## 1. System Architecture

The MMRAG Unified platform combines multimodal retrieval-augmented generation across two domains:
- **Healthcare MRAG**: Chest X-ray visual question answering using ColQwen2 dual-index retrieval and Qwen2-VL generation.
- **Scientific MRAG**: Document page QA using ColPali multi-vector visual retrieval, SciNCL text paragraph retrieval, weighted score fusion, and Qwen2-VL generation.

```
USER UI (React / Vite @ 5173) ──POST /query──► FastAPI Backend (Port 8000) ──► DomainRouter
                                                                                   │
                                                          ┌────────────────────────┴────────────────────────┐
                                                          ▼                                                 ▼
                                              Healthcare Pipeline                              Scientific Pipeline
                                              (ColQwen2 + Qwen2-VL)                           (ColPali + SciNCL + Qwen2-VL)
```

---

## 2. Healthcare Architecture

- **Retriever:** `ColQwen2Retriever` (ColPali late-interaction architecture with Qwen2-VL backbone).
- **Indexing:** Dual-index storing visual image patch embeddings (`embeddings.pt`) and text embeddings (`text_embeddings.pt`).
- **Fusion & Reranking:** `HybridRetriever` using Reciprocal Rank Fusion (RRF) and query-type classification.
- **Generator:** `Qwen/Qwen2-VL-7B-Instruct`.
- **Grounding & Verification:** `GroundingVerifier` and consensus-level confidence scoring (`HIGH`, `MEDIUM`, `LOW`).

---

## 3. Scientific Architecture

- **Visual Retriever:** `ColPaliRetriever` computing visual patch MaxSim similarity over PDF document pages.
- **Text Retriever:** `TextRetriever` querying paragraph embeddings in ChromaDB generated by SciNCL.
- **Score Fusion:** `FusionRetriever` applying min-max normalized weighted fusion (`colpali_weight=0.7`, `scincl_weight=0.3`).
- **Generator & Verification:** `Qwen2VLModel` generating document answers with citation tracking.

## 4. Frontend Architecture

- **Framework:** React 19 + TypeScript + Vite 6 + TailwindCSS + Motion.
- **API Client:** [frontend/src/services/api.ts](file:///D:/Summer%20Internship/Project/mmrag_unified/frontend/src/services/api.ts) issuing asynchronous requests to `POST /query`.
- **Image Pipeline:** Browser file selection $\rightarrow$ client-side image downscaling (768px JPEG) $\rightarrow$ base64 conversion $\rightarrow$ `image_b64` request payload.
- **Error Normalization:** `normalizeErrorMessage` prevents `[object Object]` rendering and formats backend JSON detail messages cleanly.

---

## 5. Backend Architecture

- **Framework:** FastAPI with Uvicorn ASGI server (`src.api.app:app`).
- **Endpoints:**
  - `GET /health`: Liveness probe (200 OK).
  - `GET /ready`: Readiness probe (reports loaded pipelines).
  - `GET /images/{filename}`: Secure OpenI image serving with path containment checks.
  - `POST /query`: Primary RAG execution endpoint.
